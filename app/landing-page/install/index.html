GitHub Install

Install swe.

One download on a Mac, one command on Linux. The core CLI is stdlib-only Python; nothing else gets installed.

SWE.app

The full home base: sessions, usage, limits, menu bar and widgets, with its own copy of swe bundled.

Download for Mac Needs macOS 26 or later.
or
$ brew install --cask c-wenlong/swe/swe

Just the CLI

The swe command on its own, no app.

$ brew install c-wenlong/swe/swe

Needs Python 3.11+. Nix and pipx work too.

Install script

Installs the latest released swe: the wheel is verified against the release's SHA256SUMS, then installed through uv, or into a venv under ~/.local/share/swe when uv is missing. No sudo, no shell rc edits.

$ curl -fsSL https://github.com/c-wenlong/swe/releases/latest/download/install.sh | sh

Also serve the web app and phone remote from the machine (swe remote setup --apply):

$ curl -fsSL https://github.com/c-wenlong/swe/releases/latest/download/install.sh | sh -s -- --hub
  • No Python 3.11 (Ubuntu 22.04)? The script installs uv first and brings its own interpreter.
  • Pin a version with --version=vX.Y.Z, or install a local wheel with --wheel=PATH.
  • Upgrade by running it again; remove it with uv tool uninstall swe, or, for the venv install, delete ~/.local/share/swe and the ~/.local/bin/swe symlink.

Other ways

With pipx already installed:

$ pipx install git+https://github.com/c-wenlong/swe.git

One-off with Nix: nix run github:c-wenlong/swe -- --help. The flake goes on your inputs list to keep it; see the docs.

Then

Installed the app? It carries its own swe, so nothing needs to run in the terminal: open SWE.app. On a CLI install, setup finds your agents, providers, MCP servers and skills:

$ swe setup

Then pick up where you left off, in any agent: swe session -i. More in the docs.
